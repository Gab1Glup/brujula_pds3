# 🧭 Brújula UNISON

Aplicación móvil desarrollada en Flutter que permite visualizar la orientación del dispositivo en tiempo real utilizando el sensor de brújula y la ubicación GPS.

La aplicación muestra una rosa de los vientos dinámica que rota según la orientación del dispositivo, así como la posición geográfica actual del usuario.

---

## 📖 Descripción

Brújula Unison es una aplicación móvil diseñada para demostrar el uso de sensores del dispositivo (magnetómetro y GPS) mediante Flutter.

La aplicación:

- Detecta la orientación del dispositivo.
- Muestra una rosa de los vientos animada.
- Obtiene la ubicación actual del usuario.
- Funciona en dispositivos Android.

---

## 🛠 Tecnologías Utilizadas

| Tecnología | Descripción | Versión |
|------------|------------|----------|
| Flutter | Framework multiplataforma para desarrollo móvil | 3.x |
| Dart | Lenguaje de programación usado por Flutter | 3.x |
| Android SDK | Kit de desarrollo para Android | API 35 |
| flutter_compass | Plugin para obtener datos de la brújula | ^0.8.0 |
| geolocator | Plugin para obtener ubicación GPS | ^10.x |
